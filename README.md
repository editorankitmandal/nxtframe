# Remix of yoo

Build a single-page website for NXT Frame, a video editing agency specializing in Reels, TikTok & Shorts. 

Requirements:
- Name: NXT Frame
- Font: Inter, with bold typography throughout
- Style: Minimalist aesthetic, strictly no gradients (use solid bold colors)
- Primary front page / Hero: Crisp white background with a slide-in animation for the text "NXT Frame"
- Other page section backgrounds: Bold vibrant contrast colors (solid Cobalt / Electric contrast, no gradients)
- Layout: Lean and punchy single-page flow
- Video Showcase: Rounded frame with YouTube video embed placeholders (supporting vertical short-form reels/shorts and horizontal showreel)
- Services / Specialties: Highlighting short-form retention editing, hooks, kinetic typography, pacing, and sound design
- Contact / Conversion: Quick enquiry Tally form embed/link placeholder and agency contact details at the bottom
